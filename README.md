# Wayfare — AI Travel Planning Platform

A microservice backend that turns a destination, dates, budget, and preferences
into a structured, day-by-day itinerary generated by an LLM — grounded in a real
activity catalog, delivered asynchronously, and fully editable.

> **Status:** Phase 0 — platform foundation. See [docs/BUILD-PLAN.md](docs/BUILD-PLAN.md).

## Architecture (target)

Six services behind a single gateway, database-per-service, Kafka event backbone
with the transactional outbox pattern, and an isolated AI service.

```
Client → API Gateway ─┬─ Auth Service            (auth_db)
                      ├─ User Service            (user_db)
                      ├─ Catalog Service         (catalog_db)
                      ├─ Trip Service            (trip_db)
                      ├─ Itinerary AI Service    (itinerary_ai_db) → OpenAI
                      └─ Recommendation Service  (reco_db)

           Kafka (Redpanda) ── outbox ── events between services
           Redis ── gateway rate limit · catalog cache · JWT denylist
```

## Running locally

```bash
cp .env.example .env          # then fill in secrets
docker compose up -d          # boots Postgres, Redpanda, Redis, Jaeger, Prometheus, Grafana
docker compose ps
```

| Service | URL |
|---|---|
| Redpanda Console | http://localhost:8090 |
| Jaeger (tracing) | http://localhost:16686 |
| Prometheus | http://localhost:9090 |
| Grafana | http://localhost:3000 (admin/admin) |
